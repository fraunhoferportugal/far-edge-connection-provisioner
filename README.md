# Far-Edge Connection Provisioner

**Far-Edge Connection Provisioner** enables direct communication between far-edge pods, bypassing the underlying standard communication protocol and data model used by the FITA deployment. It allows pods on far-edge devices to interact directly with each other, or with non-far-edge pods that support the same protocol and can interpret the exchanged data.

The Far-Edge Connection Provisioner improves performance and flexibility in far-edge deployments by enabling direct pod-to-pod communication, reducing dependency on centralized protocols and infrastructure, and optimizing network usage for far-edge devices.
